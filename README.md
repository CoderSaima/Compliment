# 🌟 Compliments

A web application designed to spread positivity! The app features a dynamic admin panel to manage motivational messages and a minimalist user interface where users can discover a new compliment with a single click.
---

## ✨ Features

### 🖥️ User Interface (UI)
* **Instant Positivity:** Users click a single button to generate a new, random motivational compliment instantly.
* **Smooth Transitions:** Clean and uplifting user experience designed to boost mood.

### ⚙️ Admin Dashboard
* **Content Management:** Full control over the database of compliments.
* **CRUD Operations:** Easily add new motivational phrases, update existing ones, or delete outdated text.

## 🚀 How It Works

1. The admin inputs a list of motivational compliments into the database via the admin panel.
2. The user visits the frontend application.
3. The user clicks the **"Get Compliment"** button.
4. The system randomly selects a compliment from the database and updates the screen without reloading the page.
